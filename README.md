# 🍌 สุกยัง? (SukYang) — ถามกล้วยไม่ได้ ถาม AI แทน

ระบบบอกระดับความสุกของกล้วยและจำนวนวันที่ยังกินอร่อย จากภาพถ่าย
Mini Project วิชา AI for EE (67342EPE1)

## ใช้งาน
เปิดหน้าเว็บ (GitHub Pages) แล้วเลือก
- **📷 เปิดกล้อง** ส่องกล้วยในกรอบ แล้วกด "ถ่ายและตรวจ"
- **🖼️ อัปโหลดรูป** เลือกรูปกล้วยจากเครื่อง

ระบบตอบเป็น 4 ระดับ คือ ดิบ / เริ่มสุก / สุก / งอม พร้อมเปอร์เซ็นต์ความมั่นใจ และจำนวนวันที่ยังกินสดได้
ถ้าในรูปมีกล้วยหลายลูก ระบบจะบอกผลแยกทีละลูก การประมวลผลทั้งหมดเกิดในเบราว์เซอร์ (onnxruntime-web) ภาพไม่ถูกส่งไปเซิร์ฟเวอร์

## หลักการทำงาน
1. **หากล้วย:** YOLOv8s (โมเดลตั้งต้น COCO เลือกเฉพาะคลาส banana, ภาพ 416) แบ่งไฟล์เป็น `yolo_s416.part1`–`part4`
   - ลูกที่ YOLO มองข้าม (โดนฉลากบัง/วางชิดกัน) หาเพิ่มจากบริเวณสีกล้วย HSV ที่ยังไม่มีกรอบ โดยแยกกลุ่มสีเขียวกับสีเหลือง
   - ถ้า YOLO ไม่เจอเลย ใช้บริเวณสีกล้วยที่ใหญ่ที่สุดแทน
2. **ระดับความสุก (2 โมเดลผสมกัน)**
   - **CNN (YOLOv8n-cls)** เทรนเองจากภาพกล้วย 4,087 ภาพ + ภาพจำลองแพ็กเกจ (ฟิล์มพลาสติก แสงสะท้อน ฉลาก) — `ripeness_cnn.onnx`
   - **HSV + Logistic Regression** 20 คุณลักษณะ (mean/std ของ H,S,V, สัดส่วนจุดดำ/น้ำตาล/เขียว/เหลือง/ซีด, ฮิสโตแกรมเฉดสี 8 ช่อง, จุดกระ) — ฝังใน `index.html`
   - ผสมผล CNN 80% + HSV 20% แล้วตรวจด้วยกฎ: เปลือกเขียว ≥40% = ดิบ, ≥20% = เริ่มสุก และไม่ทาย "งอม" ถ้า HSV ไม่เห็นจุดดำ/น้ำตาล
3. **จำนวนวันที่ยังกินได้:** Linear Regression จากสัดส่วนจุดดำ/สีน้ำตาล/สีเหลือง (ข้อมูลกล้วยวันที่ 0–7) MAE = 0.76 วัน

## ผลการทดสอบ (ชุด test เดียวกัน ไม่เคยใช้เทรน)
| โมเดล | ภาพปกติ (818 ภาพ) | จำลองแพ็กเกจ |
|---|---|---|
| HSV + Logistic Regression | 89.4% | 75.6% |
| CNN (YOLOv8n-cls) | 96.5% | 95.6% |
| CNN + HSV + กฎ (ที่ใช้ในเว็บ)* | 96.8% | 93.6% |

\* วัดจากชุด test สุ่ม 250 ภาพ และกับรูปกล้วยจริงในแพ็กเกจที่หามาเอง 35 ลูก ได้ถูก 34 ลูก (CNN อย่างเดียวถูก 25, HSV อย่างเดียวถูก 30)

## Dataset
- Banana Ripeness Detection Dataset (BananaImageBD), Mendeley Data — https://data.mendeley.com/datasets/ptfscwtnyz
- Banana Ripeness Classification Dataset (ไม่ใช้พันธุ์ Ambon ที่เปลือกเขียวแม้สุก)
- FruQ-DB (กล้วยเพิ่มเติมระดับสุก/งอม)
- banana_data (ภาพกล้วยบนโต๊ะไม้ พร้อมกรอบ YOLO Raw/Ripe)
- Banana ripening dataset day 0–7 (สำหรับโมเดลจำนวนวัน)

## ข้อจำกัด
- ดูจากเปลือกเท่านั้น ตรวจเนื้อในหรือราไม่ได้
- กล้วยหลายลูกที่วางชิดกันอาจถูกรวมเป็นกรอบเดียว
- พันธุ์ที่เปลือกยังเขียวแม้สุก อาจถูกทายว่าดิบ
- ถุงพลาสติกที่มีลวดลาย/ตัวหนังสือมาก อาจทำให้ผลคลาดเคลื่อน
